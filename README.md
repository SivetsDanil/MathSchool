# MathSchool · Спект.online

Сайт онлайн-школы, разработанный на заказ. На странице можно посмотреть предметы и форматы занятий, выбрать преподавателя и открыть форму заявки на консультацию.

**[Открыть статическую версию на GitHub Pages](https://sivetsdanil.github.io/MathSchool/)**

## Что есть в проекте

- **Статическая версия** — [`index.html`](index.html), стили Tailwind CSS и интерактивные элементы на Alpine.js. Карточки преподавателей загружаются из [`content/tutors.json`](content/tutors.json). Форма отправляет заявки во внешний сервис.
- **Серверная часть** — Flask-маршрут `GET /api/tutors` для подбора преподавателей по предмету и `POST /form` для обработки заявок. Для отправки уведомлений предусмотрена интеграция с Telegram Bot API.

## Как посмотреть локально

Выполните команду из корня проекта и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Готовый CSS уже лежит в репозитории. Если нужно пересобрать стили после изменений, установите Node.js и выполните `npm ci`, затем `npm run build`.

Для запуска Flask-версии нужно восстановить `templates/index.html`, установить Flask-Login и openpyxl в дополнение к [`requirements.txt`](requirements.txt) и настроить собственные учётные данные для Telegram Bot API.
